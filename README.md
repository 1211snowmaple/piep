# piep

Local-first Pixiv and FANBOX novel archiving and reading workspace.

## Links

- **Download App**: [Releases](https://github.com/1211snowmaple/piep/releases)
- **Report Bugs / Feedback**: [Issues](https://github.com/1211snowmaple/piep/issues)

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run tauri dev

# Build production app
npm run tauri build
```
