# フロント UI/UX・機能調査メモ

調査日: 2026-06-06
対象: `d75f50a`
主対象: 見た目ではなく、画面、状態、ボタン機能、入力、遷移、副作用の棚卸し

## 1. 全体構造

フロントは Tauri + Vite + React の単一アプリです。ルーティングライブラリは使わず、`src/App.tsx` が `viewMode`、`viewingDownloadId`、`workScreenMode`、`libraryEntityView` を持って画面を切り替えています。

主要な画面単位は次です。

| 状態 | 画面 | 主な役割 |
| --- | --- | --- |
| `home` | ホーム | 統計、最近の保存、タグ/作者の入口、主要機能へのショートカット |
| `library` | ライブラリ | 検索、絞り込み、作品一覧、作者/シリーズ一覧、削除、更新確認、バックアップ |
| `epub` | EPUB作成 | ライブラリ検索結果から作品を選択し、EPUB出力設定へ渡す |
| `update` | 更新管理 | 更新監視ON/OFF、更新ジョブ、候補保存、更新対象管理 |
| `pixiv` | Pixiv内蔵ブラウザ | Pixivページ閲覧、保存候補取得、ダウンロード実行 |
| `fanbox` | FANBOX内蔵ブラウザ | FANBOXページ閲覧、保存候補取得、ダウンロード実行 |
| `settings` | 設定 | Pixiv/FANBOX連携、ライブラリ再構築 |
| `viewingDownloadId != null` | 作品詳細/読書/編集 | 保存済み作品の詳細、本文閲覧、編集 |
| `libraryEntityView != null` | 作者/シリーズ詳細 | エンティティ単位で作品を操作、更新、削除、EPUB化 |

画面状態はブラウザ履歴にも保存されます。`navigateTo` が現在のスクロール位置を含む状態を `history.replaceState` し、次状態を `pushState` します。戻る/進む、マウスの戻る/進むボタンにも対応しています。

ライブラリ、EPUB、更新の一覧スクロール位置は `libraryUiState.scrollTop` と `sharedScrollRef` で復元します。作者/シリーズ詳細から戻る場合も同じ履歴復元に乗ります。

## 2. 共通シェル

左サイドバーは常時表示です。

- `ホーム`: `viewMode=home` へ移動。
- `ライブラリ`: 通常時は `viewMode=library`。作品詳細や作者/シリーズ詳細など `libraryContext` 中では `viewingDownloadId` と `libraryEntityView` を解除して一覧側へ戻る。
- `Pixiv`: `viewMode=pixiv`。認証済みならドットが有効表示。
- `FANBOX`: `viewMode=fanbox`。認証済みならドットが有効表示。
- `設定`: `viewMode=settings`。
- `LOGS`: デバッグログコンソールの開閉。

ダウンロード中は `handleNavClick` が他画面への移動を止め、トーストで「ダウンロード中は他の画面に移動できません」と通知します。

トーストは左サイドバー下部、ダウンロード候補サイドバー表示中は候補サイドバー内にも表示されます。トースト内容は同時に LOGS にも積まれます。ログは最大500件程度に抑えられます。

## 3. ホーム

`HomeDashboard` は統計ダッシュボード兼ショートカットです。Tauri外では `Preview` バッジとフォールバック統計を表示します。

主な操作:

- メトリクス `作品`: ライブラリ全体へ。
- メトリクス `お気に入り`: ライブラリの `favorite` フィルターへ。
- メトリクス `更新監視`: 更新画面へ。
- メトリクス `容量`: ライブラリ全体へ。
- 保存ペースの `開く` と各月バー: ライブラリ全体へ。
- `一覧で探す`: ライブラリへ。
- `EPUBにまとめる`: EPUB画面へ。
- `更新を見る`: 更新画面へ。
- `連携を確認`: 設定へ。
- `人気タグ` のタグ: ライブラリへ移動し、そのタグを include フィルターに設定。
- `作者` の作者名: ライブラリへ移動し、その作者を include フィルターに設定。
- `最近の保存` の作品: 作品詳細へ。
- ソース別 `Pixiv` / `FANBOX`: ライブラリのソースフィルターへ。

刷新時の注意:

- ホームは単なるランディングではなく、検索/EPUB/更新/設定/詳細へ直接入る操作入口です。
- タグ/作者クリックは一覧検索ではなく、初期フィルターつき遷移です。

## 4. Pixiv/FANBOX 内蔵ブラウザ

`pixiv` と `fanbox` は共通の `BrowserToolbar` と `BrowserWorkspace` を使います。

ツールバー操作:

- 戻る: Tauri内蔵ブラウザの `goBackEmbeddedBrowser`。
- 進む: `goForwardEmbeddedBrowser`。
- 再読み込み: `reloadEmbeddedBrowser`。
- URL表示: 現在URL。Tauri外では「Tauriアプリ内でブラウザを表示します」。
- 未連携警告: コード上は設定画面を開く。
- `候補を取得` / `更新` / `閉じる` / `前回の候補`: 現在URLと候補サイドバー状態に応じて変化。

Tauri外の挙動:

- 戻る/進む/再読み込み/候補取得は disabled。
- ブラウザ領域には「内蔵ブラウザはTauriアプリ内で利用できます」と表示。

URL追従:

- `url-changed` Tauriイベントで `currentUrl` を更新。
- SPA遷移対策として、ブラウザ画面中は1秒ごとに `getEmbeddedBrowserUrl` でURLを同期。
- サイドバーやログコンソールの開閉、ウィンドウリサイズ時に内蔵ブラウザの表示境界を再計算。

## 5. 保存候補サイドバー

保存候補の検出対象:

- Pixiv単一小説: `/novels/{id}` または `novel/show.php?id=...`
- Pixivシリーズ: `novel/series/{id}` または `novel/series/show.php?id=...`
- Pixivユーザー: `/users/{id}`。`/novels/` を含む場合は除外。
- FANBOX単一投稿: `/posts/{id}`
- FANBOXクリエイター: `subdomain.fanbox.cc` または `fanbox.cc/@creator`

候補取得の流れ:

1. Tauri外なら空サイドバーで制限メッセージ。
2. 内蔵ブラウザURLを取得。
3. URLが取得できなければ、前回候補があれば再表示。
4. 未対応URLなら、前回候補があれば再表示、なければ空表示。
5. 認証チェック。Pixiv/FANBOX未連携ならエラー。
6. URL種別に応じてAPIを呼び候補リストを作成。
7. 候補サイドバーを `analysis` として表示し、前回候補としてキャッシュ。

候補サイドバー操作:

- `すべて選択`: 全候補を selected にする。
- `すべて解除`: 全候補を selected=false にする。
- 候補カードクリック / Enter / Space: 個別選択をトグル。
- `選択した n 件を保存`: 保存実行。
- 保存中: 各候補が `待機中`、`保存中`、`保存完了`、`保存済み`、`失敗` に変わる。
- 保存完了後: `ライブラリへ移動して読む` でライブラリへ移動し、サイドバーを閉じる。

保存実行の副作用:

- 既存作品があり `watchUpdates=false` ならスキップ。
- 既存作品があり `watchUpdates=true` なら更新確認として再取得。
- 新規または更新が成功すると `downloadAndSave`。
- 保存後、作者/シリーズのプロフィール更新をベストエフォートで実行。
- 結果はトーストと LOGS に出る。

## 6. ライブラリ一覧

ライブラリは最重要機能です。通常一覧、EPUB作成、更新管理の3画面は同じ `LibraryView` を使い、上部ワークフロータブで切り替わります。

### 6.1 ワークフロータブ

- `一覧`: 通常ライブラリ。
- `EPUB`: EPUB選択モード。
- `更新`: 更新管理モード。

切替時は `App.handleNavClick` 経由で `viewMode` が変わり、一覧状態は `libraryUiStateForMode` で初期化されます。`gallery` / `compact` は保持されます。

### 6.2 表示切替

- `ギャラリー`: カード幅220px、推定高さ360px。
- `コンパクト`: カード幅338px、推定高さ134px。

仮想グリッドで行単位にレンダリングし、スクロール末尾付近で追加読み込みします。

### 6.3 検索

検索ボックス機能:

- 入力は300msデバウンスで `query` に反映。
- `Ctrl/Cmd + K` で検索ポップオーバーを開く。
- `Enter`: 最近の検索に保存し、ポップオーバーを閉じる。
- `Escape`: ポップオーバーを閉じる。
- IME変換中は候補取得を抑制。
- 検索候補は `searchSuggest` で取得。
- 候補クリックで `tag:"..."`、`author:"..."`、`series:...` などの検索トークンを追記。
- `検索: {query}` でそのクエリを実行。
- `意味も含めて探す` で検索モードを semantic に切り替えて実行。
- `保存検索に追加` で保存検索へ。
- `保存検索` と `最近の検索` から再適用可能。
- 構文ヒント: `tag:`、`author:`、`series:`、`source:pixiv`、`source:fanbox`、`id:`、`url:`、`-term`、`"phrase"`。

検索モード:

- `Smart`
- `Exact`
- `Semantic`

検索インデックス:

- 未完了時は進捗を検索欄に表示。
- semantic ready 時は GPU/CPU と chunk 数を表示。
- 未インデックス作品がある場合、`startSearchRebuildIndex(128)` を起動し、`search-index-progress` で状態更新。

### 6.4 ソート/ソース/フィルター

ソース:

- すべて
- Pixiv
- FANBOX
- お気に入り

ソート:

- 関連度順
- ダウンロード日順
- 投稿日順
- タイトル順
- 著者順
- サイズ順

クエリ入力中かつソートが未操作なら自動で関連度順になります。クエリを消して関連度順のままなら投稿日順へ戻ります。

昇降順:

- `↓` / `↑` ボタンで `desc` / `asc` を切替。

フィルターパネル:

- `AND` / `OR`。タグフィルターの結合条件。
- 適用中チップ。クリックで検索、ソース、文字数、アセット、更新監視フィルターを解除。
- タグ/作者チップ。クリックごとに include、exclude、解除を循環。
- 文字数プリセット: すべて、1万字未満、1万から3万字、3万から5万字、5万から10万字、10万字以上。
- 文字数直接入力: 最小、最大。
- アセット: すべて、テキストのみ、画像あり、その他ファイルあり、画像+その他あり。
- 更新確認: すべて、更新ON、更新OFF。
- タグ候補検索、著者候補検索。
- `フィルターをクリア`: 検索、タグ、作者、文字数、アセット、更新監視を初期化。
- パネル外クリック、閉じるボタンでパネルを閉じる。

### 6.5 サブタブ

- `作品`: 通常の作品グリッド。
- `作者`: 作者エンティティカード一覧。クリックで作者詳細。
- `シリーズ`: シリーズエンティティカード一覧。クリックでシリーズ詳細。

作者/シリーズタブでは `searchVal` で表示名やキーをフロント側フィルターします。

### 6.6 通常一覧のカード操作

通常モードの作品カード:

- カードクリック: 作品詳細へ。
- 表紙上の更新監視バッジ: `watchUpdates` をトグル。
- 表紙上のお気に入りバッジ: `favorite` をトグル。
- シリーズリンク: シリーズ詳細へ。
- 作者名: 作者詳細へ。
- タグ: タグフィルターを include、exclude、解除で循環。
- `+n` タグ: ツールチップに全タグを表示。ツールチップ内タグもフィルター循環可能。

### 6.7 一括削除モード

通常一覧のゴミ箱ボタンで削除モードへ入ります。

- カードクリック: 選択/解除。
- `全選択`: 現在の絞り込み条件に一致する全作品をDBから取得して選択。
- `全選択解除`: 選択解除。
- `削除確定`: 確認ダイアログ後、選択作品を完全削除。アセットや関連データも対象。
- `キャンセル`: 削除モード終了、選択解除。

### 6.8 更新モード

`viewMode=update` の一覧カード:

- カードクリック: その作品の更新監視ON/OFFをトグル。
- 上部の全選択風ボタン: 表示中/絞り込み対象作品を一括で更新ONまたはOFF。
- 更新チェックボタン: 監視中の作品、著者、シリーズの更新ジョブを開始し、自動保存まで行う。
- `更新管理`: 更新サイドバーの開閉。

`LibraryView` 内には `isUpdateMode` という旧式の更新モード分岐も残っていますが、現在の主要導線は `viewMode=update` です。

### 6.9 バックアップ

通常一覧のバックアップドロップダウン:

- `バックアップ作成`: ZIP保存先を選び、全データを `exportAllZip`。
- `バックアップ復元`: ZIPファイルを選び、`importZip`。復元件数をトースト表示し、一覧再取得。

Tauri外では無効です。

## 7. 作者/シリーズ詳細

`PersonView` と `SeriesView` はライブラリ配下の深掘り画面です。

共通機能:

- プロフィール/シリーズ情報、保存済み作品、履歴数、最終確認日時を表示。
- 表示切替: ギャラリー/コンパクト。`entity.viewMode` として保存。
- 作品カードクリック: 通常時は作品詳細へ。削除/EPUB選択時は選択トグル。
- シリーズリンク: シリーズ詳細へ。
- `さらに読み込む`: ページング。
- 外部リンクアイコン: アプリ内ブラウザで元ページを開く。

アクションバー:

- 更新チェック: プロフィールと新作を確認。Pixiv作者ならユーザー小説、FANBOX作者ならクリエイター投稿、Pixivシリーズならシリーズ小説を取得して保存/更新/既存/失敗を集計。
- 削除: 削除選択モードへ。
- 削除モードの全選択/全解除。
- 削除確定: 確認後、選択作品を完全削除。
- キャンセル: 選択終了。
- バックアップ: その作者/シリーズだけ `exportEntityZip`。
- EPUB: 作品全体を選択してEPUBサイドバーへ渡す。選択中はカードクリックで対象を調整。

刷新時の注意:

- 作者/シリーズ詳細は読み物情報ページではなく、更新取得、削除、バックアップ、EPUB化を含む作業画面です。
- エンティティの更新は保存済み作品の追加にもつながります。

## 8. 作品詳細

作品詳細は `ContentViewer` です。上部でバージョンを選び、その版を基準に概要/本文/アセット/JSON/差分を表示します。

上部操作:

- バージョン選択: 閲覧中バージョンを切替。
- 更新確認: その作品だけ `startUpdateJob({ scope: "work", mode: "auto_save" })`。更新があればメタデータ再読込。
- 保存元を開く: Pixiv/FANBOXの元URLをアプリ内ブラウザで開く。
- 削除: 1バージョンしかなければ作品削除。複数バージョンなら閲覧中バージョン削除。最新版削除時は直前バージョンを最新として復元する想定。
- フォルダを開く: JSONのあるフォルダをファイルマネージャで表示。
- エクスポート: 指定フォルダへ単体ファイル保存。
- 読む: 読書専用画面へ。
- 編集: 編集画面へ。
- EPUB: その作品を選択し、EPUBサイドバーを開閉。

ヒーロー領域:

- 表紙クリック: ライトボックス表示。背景クリックで閉じる。
- 更新監視バッジ: 作品の更新確認ON/OFF。
- お気に入りバッジ: favorite ON/OFF。
- シリーズリンク: シリーズ詳細へ。
- 作者名: 作者詳細へ。
- タグ: ライブラリへ移動し、そのタグを include フィルターに設定。
- 説明文内リンク:
  - Pixiv/FANBOXリンクはアプリ内ブラウザへ。
  - それ以外のURLはOS既定ブラウザへ。
- `続きを読む` / `閉じる`: 説明文の折りたたみ。

タブ:

- `概要`: ソース、ID、著者、シリーズ、種類、アセット数、最新/閲覧中バージョン、本文文字数、ハッシュ、ダウンロード日、投稿日、更新日。
- `本文`: HTML本文プレビュー。長文はページ分割。`前へ`、ページ番号、`次へ`。Aaパネルで背景、書体、文字サイズ、行間を調整。
- `アセット`: 画像はクリックでライトボックス。その他ファイルはクリックで開く。
- `JSON`: 元JSONまたは加工済みJSONを表示。
- `差分`: Before/Afterバージョンを選んで行差分を表示。追加/削除件数をバッジ表示。

内部リンク解決:

- 詳細や本文内リンクが保存済み作品URLなら、まずDBから保存済み作品を探して詳細へ開く。
- 未保存なら Pixiv/FANBOX 内蔵ブラウザへ遷移し、そのURLを開く。

## 9. 読書専用画面

`ReaderView` は詳細タブ内の本文ビューとは別の専用リーダーです。

操作:

- 戻る: 作品詳細へ。
- 保存元を開く: アプリ内ブラウザへ。
- 編集: 編集画面へ。
- 読書設定: 右サイド設定パネルを開閉。
- 作者名クリック: 現状は作者名をトースト表示。
- スクロール: 進捗を計算し、作品ごとにスクロール位置を localStorage 保存。

設定パネル:

- 標準に戻す。
- 文字サイズ: スライダー、マイナス/プラス。
- 行間: スライダー、マイナス/プラス。
- テーマ: 紙/白/黒。
- 書体: 明朝/ゴシック。
- 読み幅: 狭め/標準/広め。
- 先頭へ戻る。

保存キーは `piep-reader-v2-*` 系です。

## 10. 編集画面

`WorkEditor` はブロック編集型です。

上部操作:

- 戻る: 詳細へ。
- 読む: 読書画面へ。
- 下書き保存: `saveWorkDraft`。エディタ/リーダーの query を invalidate。
- 有効化: 下書き保存後、`activateWorkEdit` で編集版を有効にする。

ブロック操作:

- 上へ/下へ: ブロック並べ替え。
- 種別: 段落、見出し、区切り。
- 画像ブロック: 既存画像アセットを選択。
- テキスト入力: 段落または見出し。
- 挿入: 段落、見出し、挿絵、区切り。
- 挿絵: 画像ファイル選択、`importWorkAsset` 後に画像ブロック追加。
- 削除: ブロック削除。最低1ブロックは残す。

刷新時の注意:

- 編集は原本破壊ではなく、下書き/有効化のリビジョンモデルです。
- 読書画面は active edit revision を表示できるため、詳細/読書/編集の同期が必要です。

## 11. EPUBサイドバー

`EpubSidebar` はライブラリEPUB画面、作品詳細、作者/シリーズ詳細から共通利用されます。

基本操作:

- 閉じる。
- テンプレート選択:
  - 自動判別
  - 取得済みテンプレート一覧
- 画像圧縮ON/OFF。
- EPUBにエクスポート。

出力先:

- 1件選択: EPUBファイル保存ダイアログ。
- 複数選択: 出力先フォルダ選択、バッチ出力。

自動判別:

- Pixiv作品は `pixiv` テンプレート側。

## 12. 更新管理サイドバー

`UpdateSidebar` は更新画面から開閉します。

タブ:

- `作品`: 更新監視ONの作品一覧。
- `著者`: 監視対象作者と、ライブラリから追加できる作者候補。
- `シリーズ`: 監視対象シリーズと、ライブラリから追加できるシリーズ候補。
- `結果`: 新作候補とログ。

開始操作:

- `すべてチェック`: 全対象を check_only。
- `自動保存込み`: 全対象を auto_save。
- `表示中だけ`: 現在タブ対象を check_only。結果タブなら全対象。

ジョブ操作:

- running/queued: `停止`。
- paused/auth_required/failed: `再開`。failed時は failed retry。
- terminalでなければ `キャンセル`。
- 進捗バー、状態、処理数、候補数、保存数、エラー数を表示。

著者/シリーズ対象:

- ON/OFFバッジ。
- `停止` / `再開`: `setUpdateTargetEnabled`。
- `削除`: 更新監視から削除。
- 追加候補の `追加`: `upsertUpdateTarget`。

結果:

- 候補は仮想リスト。
- 候補チェックボックスで選択。
- 新規候補/失敗候補は自動選択される。
- `全選択` / `全解除`。
- `選択候補を保存`: `saveUpdateJobCandidates`。
- ログは仮想リストで表示。

## 13. 設定

`AuthSettings` が担当します。

Pixiv連携:

- 起動時に保存済み refresh token があれば検証。
- `Pixiv と連携を開始`: Tauri webviewログイン。成功時 token を store に保存。
- 連携済み表示: アバター、名前、ID、`連携を解除`。
- 解除: 確認ダイアログ後 token 削除。

FANBOX連携:

- 起動時に session id と user agent があれば検証。
- `FANBOX と連携を開始`: Tauri webviewログイン。cookie と user agent を store に保存。
- 連携済み表示: アバター、名前、ID、`連携を解除`。
- 解除: 確認ダイアログ後 session と user agent 削除。

ローカルライブラリ再構築:

- 確認ダイアログ後、downloads フォルダからDBと検索インデックスを再構築。
- 完了ダイアログと復元件数を表示。

Tauri外:

- 連携開始、再構築はエラーバナーで「この操作はTauriアプリ内でのみ利用できます。」を表示。

## 15. 実行確認結果

確認環境:

- `http://127.0.0.1:1420`
- Tauri外の開発ブラウザ

確認できたこと:

- ビルドは成功: `npm run build`
- ホーム、ライブラリ、EPUB、更新、Pixiv、設定画面の初期表示を確認。
- Tauri外では保存データが空扱いになり、`Preview` 表示になる。
- Pixiv画面では内蔵ブラウザ操作と候補取得が disabled。
- 設定画面のPixiv連携開始クリックで Tauri外エラー表示。
- LOGS開閉を確認。

実行時に見つかった注意点:

- ブラウザコンソールで `Maximum update depth exceeded` が連続発生。表示自体は続くが、刷新前に原因特定が必要。
- Pixiv/FANBOXツールバーの未連携ボタンはコード上は設定遷移だが、開発ブラウザの自動操作では遷移を確認できなかった。左ナビからの設定遷移は確認済み。
- `ContentViewer` の本文タブにも読書設定があり、`ReaderView` にも別系統の読書設定がある。保存キーも別なので、刷新時に統合するか、用途差を明確化した方がよい。
- 設定画面で連携成功後、親の `isPixivAuthed` / `isFanboxAuthed` は `viewMode` 変化時に再チェックされるため、連携直後のサイドバー認証ドット更新は即時ではない可能性がある。

## 16. 機能刷新で維持すべき要件

必ず維持したい機能:

- 画面状態とスクロール位置を履歴で復元できること。
- ホームからライブラリ、EPUB、更新、設定、作品詳細へ直接移動できること。
- ライブラリ検索は Smart/Exact/Semantic、構文トークン、候補、保存検索、最近検索を維持すること。
- タグ/作者フィルターは include/exclude/解除の3状態を維持すること。
- ライブラリは作品/作者/シリーズを同じ検索文脈から切り替えられること。
- 通常一覧、EPUB選択、更新監視、削除モードでカードクリックの意味が変わることを明確に扱うこと。
- 作品詳細はバージョン選択、更新確認、削除、差分、JSON、アセット、フォルダ表示、単体エクスポートを維持すること。
- 保存済みリンクはDB内作品を優先して開き、未保存なら内蔵ブラウザへ送ること。
- 作者/シリーズ詳細から、その単位で更新取得、削除、バックアップ、EPUB化できること。
- EPUB出力は単一/複数で保存先UIが変わること。
- EPUBテンプレート管理と画像圧縮詳細設定を維持すること。
- 更新管理はジョブ状態、停止/再開/キャンセル、候補選択保存、ログ表示を維持すること。
- Pixiv/FANBOXの候補取得はURL種別ごとの一括/単体を維持すること。
- Tauri外プレビュー時は危険操作やTauri依存操作を無効化し、理由を表示すること。

刷新時に整理したい機能課題:

- ライブラリに機能が集中しすぎているため、通常一覧、選択作業、更新作業のモード境界を見失いやすい。
- `isUpdateMode` と `viewMode=update` のような近い概念が併存している。
- 読書設定が詳細本文タブと専用リーダーで二重化している。
- ランタイムの更新深度エラーを放置したままUI刷新すると、原因追跡が難しくなる。
- Auth設定後の親状態更新はイベントまたはコールバックで即時同期した方がよい。
