# piep とは何か

piep は、pixiv と pixivFANBOX の小説・記事を**自分の PC に丸ごと残して読むための
デスクトップアプリ**である。保存・検索・読書・書き出しまでが、ネットにつながって
いなくても完結する。

## 中心にある考え

**手元にあることが、読めることの前提である。**

配信元のサービスは、作品を消すことも、閲覧条件を変えることも、サービス自体を
畳むこともできる。piep が解こうとしているのはその一点で、「読みたいものが
読みたいときに読める」状態を、他人の都合から切り離して持つための道具である。

したがって、機能の優劣を判断するときの物差しはいつも同じになる。

> その機能は、手元のライブラリを**より確実に**、**より読みやすく**するか。

## 何をするか

| | |
|---|---|
| 保存する | 内蔵ブラウザで pixiv・FANBOX を開き、そのページから作品・シリーズ・作者をまとめて取り込む |
| 探す | 1万件を超えても待たされない全文検索。表記ゆれを吸収し、意味の近さでも探せる |
| 読む | 書体・文字サイズ・行間・背景色を選べるリーダー。読みかけの位置を覚える |
| 直す | 取り込んだ本文をブロック単位で編集する。原本は残り、編集は別リビジョンになる |
| 追う | 監視している作品の改稿、作者の新作、シリーズの続編をまとめて確認する |
| 持ち出す | 選んだ作品を EPUB 3 として書き出す |
| 守る | ライブラリ全体のバックアップと検証付き復元、容量と索引の診断 |

## 何をしないか（非目標）

ここに挙げたものは「まだ作っていない」のではなく、**作らないと決めている**。

### 再配布の手助けをしない

piep は、自分が閲覧できる作品を自分用に残す道具である。保存したデータの権利は
各作者にある。共有機能、公開機能、他人への配信を助ける機能は作らない。
EPUB 書き出しは持ち出しのためであって、配布のためではない。

### サーバーを持たない

アカウントも、同期も、クラウド保存もない。処理と保存先はすべて利用者の PC の
中で完結する。piep が外部へ通信するのは、pixiv と FANBOX からデータを取得する
ときだけである。

同期がないことは制約だが、**同期がないからこそ、サービスが止まってもライブラリは
生き続ける**。これは中心の考えから直接出てくる帰結であって、手を抜いた結果ではない。

### 大量取得の道具にしない

同時実行数の既定値は控えめにしてある。速く大量に取ることを目的にした機能や、
規約の制限を迂回する機能は作らない。

### Windows 以外を対象にしない

意味検索の GPU 実行は DirectML、内蔵ブラウザと認証は WebView2、実ウィンドウを
起動するテストも Windows を前提にしている。**動作を確認できていない環境向けの
インストーラーを配ることは、誰も起動したことのないバイナリを配ることに等しい。**

ソースからのビルドは Tauri が対応する他の OS でも試せるが、動作は保証しない。

### 自動判定を確定データにしない

コレクションの候補生成のように、アプリが推測する場面はある。しかしその結果を
利用者の確認なしに確定させることはしない。題名や本文が似ているだけでは、同じ
連載なのか、同じ世界の別作品なのか、単に題材が似ているだけなのかを区別できない。

**自動処理の役割は候補と下書きを作るところまでで、決める権限は利用者に残す。**
