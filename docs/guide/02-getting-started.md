# はじめる

## 入れる

[Releases](https://github.com/1211snowmaple/piep/releases) から、Windows 向けの
インストーラー（`.msi` または `.exe`）をダウンロードします。

コード署名は行っていないため、初回起動時に Windows の警告が出ることがあります。

### 動作環境

| | |
|---|---|
| OS | Windows 10（64bit）以降 |
| WebView2 ランタイム | Windows 11 には標準で入っています。無い場合はインストーラーが導入します |
| 空き容量 | 保存した作品のぶん。意味検索を使う場合はモデル用に数百 MB |

### なぜ Windows だけか

意味検索の GPU 実行（DirectML）、内蔵ブラウザと認証（WebView2）、実際のウィンドウを
起動するテストが、いずれも Windows 前提です。動作を確かめられている環境が Windows
しかないので、確かめていない OS 向けの配布物は作りません。

ソースからのビルドは Tauri が対応する他の OS でも試せますが、動作は保証していません。

## 最初の保存まで

1. **設定 → サービス接続** から、pixiv と FANBOX にログインします
2. **保存** を開き、内蔵ブラウザで保存したいページを表示して「候補を取得」を押します
3. 保存する項目を選んで実行すると、**ライブラリ** に並びます

あとは読むだけです。

## 更新

新しい版が出るとアプリが知らせます。更新の確認は GitHub Releases への通信だけで、
ライブラリの内容は送られません。

## 困ったとき

| 症状 | 見るところ |
|---|---|
| 取得が失敗する | **設定 → サービス接続** でログインが切れていないか |
| 検索に出てこない | **ライブラリ診断** で索引の完成度を見る。作り直しもここから |
| 意味検索が使えない | **設定** で意味索引を作る。モデルの初回取得に時間がかかります |
| 動作が重い | **ライブラリ診断** から SQLite と検索索引の最適化を実行 |

直らないときは [Issues](https://github.com/1211snowmaple/piep/issues) へ。
