# データの置き場所とバックアップ

## どこにあるか

すべて `%APPDATA%\io.github.u1211snowmaple.piep` の下にあります。実際のパスは
**設定 → ローカルライブラリ** に表示されます。

| 場所 | 中身 |
|---|---|
| `piep.db` | 作品のメタデータ、タグ、履歴、更新監視の設定 |
| `downloads/` | 本文の JSON と画像。取得元・作品ごとのフォルダー |
| `collection-covers/` | 選んだコレクション表紙の管理コピー。バックアップ対象 |
| `templates/` | EPUB テンプレート（テンプレートスタジオで編集したもの） |
| `delete-staging/` | 削除をクラッシュ安全に完了するための一時隔離。次回起動時に復旧または完了 |

データベースは <!--stat:tables.total-->31<!--/stat--> のテーブルでできています。
中身の一覧は [スキーマ](../reference/schema.md) にあります（ソースから生成しています）。

## 取り込んだ本文は書き換わらない

編集しても、取り込んだままの本文は残ります。編集は別のリビジョンとして保存される
ので、いつでも元に戻せます。これは piep がいちばん強く守っている約束で、理由は
[利用者のライブラリを壊さない](../policy/02-principles.md) に書いてあります。

## バックアップ

**設定 → ローカルライブラリ** から、マニフェストと分割 ZIP として書き出せます。
復元は、取り込む前に中身を検査します。

## 旧版から新しい保存先への移行

アプリ識別子を変更した版は、旧版と別の保存先を使います。**旧版と新版の両方を閉じ、
新版を初めて起動する前**に移行してください。旧版の設定画面に表示される保存先は
`downloads` フォルダーなので、その一段上にある `piep.db` を含むフォルダーを
移行元に指定します。

1. 旧版で分割バックアップを書き出し、マニフェストと ZIP 一式を安全な場所に保管します。
2. リポジトリの `tools/migrate-app-data.py` に移行元と
   `%APPDATA%\io.github.u1211snowmaple.piep` を指定して、まず検査だけ実行します。
3. 両アプリが閉じていることを確認し、同じコマンドに `--execute` を付けて実行します。
4. 新版を起動し、作品数、本文と画像、編集、読書位置、設定を確認します。

移行ツールは元のフォルダーを変更せず、新しい保存先を別に作ります。十分な空き容量が
必要です。確認が済むまで元のフォルダーと分割バックアップを保管してください。
旧版のアプリ内更新から識別子変更版へ直接入れ替えず、新版のインストーラーを使います。

本ソフトウェアは無保証で提供されます。大切なライブラリは定期的に書き出してください。

## 保存フォルダーからの取り込み

すでに手元にある保存フォルダーを、あとから piep のライブラリへ取り込めます。
同じ画面から実行します。

## 権利について

保存したデータの権利は各作者にあります。再配布や公開はしないでください。
利用にあたっては pixiv および FANBOX の利用規約に従ってください。
