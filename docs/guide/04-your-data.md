# データの置き場所とバックアップ

## どこにあるか

すべて `%APPDATA%\io.github.u1211snowmaple.piep` の下にあります。作品を収めた棚の
実際のパスは **設定 → 保存とバックアップ** に表示されます。

| 場所 | 中身 |
|---|---|
| `library/` | 棚。作品の本文・画像・添付、メタデータ、タグ、版の履歴、編集、コレクション、更新監視 |
| `library/library.json` | 棚の名札。これがあるフォルダーを棚として開きます |
| `library/library.db` | 台帳。どの作品がどの版で、どのファイルを持つか |
| `library/objects/` | ファイルの実体。中身の指紋で置くので、同じ画像は一つしか持ちません |
| `library/derived/` | 検索の索引など、台帳から作り直せるもの |
| `models/` | 意味検索のモデル。棚の外に置くので、バックアップには入りません |
| `templates/` | EPUB テンプレート（テンプレートスタジオで編集したもの） |
| `downloads/` | 保存フォルダーから取り込むときの置き場（下の「保存フォルダーからの取り込み」） |

棚の中身は台帳とファイルの実体でひと組です。中のファイルを手で動かしたり消したりしないでください。

## 取り込んだ本文は書き換わらない

編集しても、取り込んだままの本文は残ります。編集は別のリビジョンとして保存される
ので、いつでも元に戻せます。これは piep がいちばん強く守っている約束で、理由は
[利用者のライブラリを壊さない](../policy/02-principles.md) に書いてあります。

## バックアップ

**設定 → 保存とバックアップ** の「棚のバックアップを作る」で、選んだフォルダーに棚そのものを
写します。写したあと中身をすべて検査し、通ったものだけをバックアップとして残します。
写している間も、作品の保存や読書はそのまま続けられます。

復元は「バックアップから復元」で選びます。すぐには入れ替えず、検査を通った写しを予約して、
次にアプリを起動したとき、棚を開く前に入れ替えます。今の棚は消さずに
`library.before-restore-<日時>` として隣へ退け、選んだバックアップも手元に残ります。
入れ替えに失敗したときは、退けた棚を元に戻します。

作者・シリーズの画面からは、その作品だけを写したアーカイブを作れます。アーカイブは棚の
入れ替えには使えません。復元で選ぶと、今の棚に無い作品だけを足します。

## 保存フォルダーからの取り込み

`downloads/` に置いた保存フォルダー（`<取得元>/<作品の番号>/v<版>/`）のうち、棚にまだ無い
作品を、取り寄せずにそのまま棚へ取り込めます。**設定 → 保存とバックアップ** の
「保存フォルダーを調べる」から実行します。棚にある作品や、棚から外した作品には触れません。

本ソフトウェアは無保証で提供されます。大切なライブラリは定期的にバックアップしてください。

## 権利について

保存したデータの権利は各作者にあります。再配布や公開はしないでください。
利用にあたっては pixiv および FANBOX の利用規約に従ってください。
