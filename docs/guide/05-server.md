# サーバー（β）

携帯から、家の外でもライブラリを検索して読めるようにする機能です。**β** なので、API と保存形式は予告して変えることがあります。

ライブラリを出す形は 2 つあります。

| | この PC をサーバーにする | 単独サーバー |
|---|---|---|
| 読める間 | この PC が動いている間 | サーバーの機械が動いている間 |
| 用意するもの | なし | 常時動いている Windows 機 |
| ライブラリの更新 | そのまま | デスクトップ版から差分を送る |

どちらも入れるまでは何も動きません。

## この PC をサーバーにする

1. **設定 → サーバー** で **この PC** を選び、携帯からの接続方法を選んで **開始** を押します。
   - **この PC に直接接続する:** 選んだネットワークで、自己署名の証明書を使って待ち受けます。
   - **トンネルやリバースプロキシを経由する:** `127.0.0.1:38777` を平文で待ち受けます。公開 URL からここへ転送する仕組みを用意してください。
2. **携帯を追加** を押し、画面の手順に沿って携帯を登録します（[携帯を登録する](#_5-携帯を登録する)）。

## 単独サーバーを置く

常に動いている Windows の機械に置くと、デスクトップ版の PC を閉じていても携帯から読めます。

### 1. 入れる

[リリース](https://github.com/1211snowmaple/piep/releases/latest)から `piep-server-<版>-windows-x64.zip` を取ってきて展開し、
`piep-server.exe` を開きます。管理者権限を求められたら許可してください。質問は次の 2 つです。

- **置き場所:** ライブラリが入るので、大きいドライブを選べます。既定は `C:\ProgramData\piep-server` です。
- **携帯からの接続方法:**
  - **トンネルやリバースプロキシを経由する:** 公開 URL で、どこからでも使えます。`127.0.0.1:38777` で待ち受けるので、
    公開 URL からここへ転送する仕組みを用意してください。何を使うかは自由です。先に公開 URL を用意しておくと、
    そのまま入力できます。
  - **この PC で直接待ち受ける:** 自己署名の証明書で `38777` 番を開きます。接続できる範囲は、この PC のネットワークによります。

終わると起動時に自動で動くように登録され、**管理者用の登録文字列**が画面に出ます。30 分有効で、一度だけ使えます。
画面の外に残さないでください。出し直すときは次のコマンドを管理者権限で動かします。

```powershell
& "C:\ProgramData\piep-server\piep-server.exe" admin-pair --data "C:\ProgramData\piep-server"
```

管理者は 1 台だけです。すでに登録されているときは、この PC を入れ替える場合に限って `--replace` を付けます。その文字列で登録すると、今の管理者は接続できなくなります。

質問はコマンドの引数で飛ばせます。起動の仕組みを自分で用意するなら `--no-task` を付けます（管理者権限は要りません）。

```powershell
piep-server install --data D:\piep-server --expose proxy --url https://<公開 URL>/
```

### 2. 落ちたとき・更新

- 落ちても自分で立ち上がります。記録は `<置き場所>\state\watchdog.log` にあります。
- 新しい版が出ると、夜間（既定は 3 時から 6 時）に自動で更新します。止まるのは数十秒です。起動しない版は自動で前の版に戻します。
- 自動の更新を切っても、新しいバージョンの確認は続けます。切っている間は、押したときだけ更新します。
- デスクトップ版の **更新を確認** と、[管理画面](#管理画面)の **更新** から操作できます。自動の切り替えと時間帯は管理画面で変えられます。

- やめるときは `piep-server uninstall` です。起動時の登録を消して止めます。置き場所は消さないので、要らなければ自分で消してください。

### 3. 設定を変える

`server.toml` は `<置き場所>` にあります。書き換えたら再起動してください。

| 置き方 | 設定 |
| --- | --- |
| トンネルやリバースプロキシの裏 | `listen` は `127.0.0.1` のまま。`public_url` に公開 URL を書く |
| 直接待ち受ける | `listen = "0.0.0.0:38777"`、`tls = "self-signed"` |
| 自分の証明書 | `tls = { cert = "...", key = "..." }` |

`127.0.0.1` 以外で待ち受けるには `tls` が必須です。無ければ起動しません。

インターネットへ出すときは `admin_listen` で管理用のアドレスを分け、**`listen` のアドレスだけ**を公開してください。
公開したアドレスには、管理の API も管理画面もありません。デスクトップ版と管理画面は、家の中のネットワークや VPN から管理用のアドレスにつなぎます。

### 4. デスクトップ版から接続する

**設定 → サーバー** で **いつも動いている PC** を選び、登録文字列を貼り付けます。管理者の鍵は Windows の資格情報マネージャーに
保存されます。接続したら **今すぐ送る** を押してください。初回はライブラリの全部を送るので時間がかかります。中止しても、次回は
その続きから送ります。

**自動で送る** をオンにすると、ライブラリを変更してから 5 分間、ほかの変更がなければ送ります。

送るのはライブラリの DB の写しと、本文・画像・作者とシリーズの画像・コレクションの表紙です。pixiv と FANBOX のログイン情報は送りません。

### 5. 携帯を登録する

**携帯を追加** を押すと、手順が 2 つ順に出ます。QR は一度に 1 つだけ表示します。

1. アプリの QR を携帯のカメラで読み、配布ページから Android 版を入れます。入っていれば、そのまま次へ進みます。
2. 登録の QR を、Android 版の「設定 → サーバーとの接続 → QR を読む」で読み取ります。10 分間有効で、一度だけ使えます。

登録の解除はすぐに反映されます。

Android 版の更新は、アプリの「設定 → アプリの更新」から行います。OS の確認に答えると上書きされ、保存した作品と登録は残ります。

### 管理画面

更新、端末、記録などは、サーバーの URL をブラウザで開いて操作します。デスクトップ版の **管理画面を開く** から入ると、ログインは要りません。
管理者のアカウントは、はじめて開いたときに作ります。別の PC や携帯のブラウザからは、そのアカウントでログインします。

| 項目 | できること |
| --- | --- |
| 概要 | 今の問題、バージョン、空き容量、最近の出来事 |
| 更新 | 確認と更新、自動の切り替えと時間帯、履歴、前のバージョンへ戻す |
| 端末 | 携帯の追加と解除、デスクトップ版の入れ替え、ログイン中のブラウザの確認 |
| ライブラリ | 受け取った内容、容量、検索の索引 |
| 記録 | ログイン、更新、端末、受信の記録 |
| 接続と安全 | 待ち受けの確認、名前とパスワードの変更、管理画面を止める |

前のバージョンへ戻すと、更新のあとに受け取ったライブラリと端末の登録も、更新の前の状態に戻ります。ライブラリはデスクトップ版から送り直せます。

パスワードを忘れたときは、サーバーで次を実行します。表示されたリンクから決め直すと、今のログインはすべて切れます。

```powershell
piep-server admin-password --data "C:\ProgramData\piep-server"
```

管理画面を止めると、読むことと送信は続きます。戻すときは `piep-server admin-web --data <置き場所> --enable` を実行します。

公開用のアドレスしか持たないサーバーでは、管理画面は開きません。`server.toml` に `admin_listen` を書いて分けてください。

## 守り

- 無認証で答えるのは接続の確認と登録だけです。ライブラリはすべて鍵が要ります。
- 管理画面のパスワードは 15 文字以上で、続けて間違えると待ち時間が延びます。大事な操作の前には、もう一度パスワードを聞きます。
- 管理画面は、知らない名前のアドレスや別のサイトからの要求を断り、外の資産を読みません。
- 鍵はサーバーにハッシュだけが残ります。登録文字列は記録に残りません。
- 登録の試行は 1 分に 10 回までです。
- 応答に、サーバーの中のパスは出ません。
- 読み手の鍵では、ライブラリを書き換えられません。読み手が変えられるのは読書位置だけです。
- サーバーは、携帯が読むのに使わない表（更新確認の対象、AI の下書きなど）を受け取りません。
- 一覧から消えたファイルは、すぐには消さず `library-trash` に 7 日残します。直前の DB は `library\piep.db.previous` に残ります。

## 今のところできないこと

- サーバーでの更新確認・保存（デスクトップ版で行って送ります）
- 携帯からのライブラリの変更
- 意味検索（全文検索は使えます）
- 動画・音声・PDF の資産の読み取り
- デスクトップ版の読書位置との同期（携帯どうしは同期します）

先の予定は [仕様](../plan/server-mode.md) にあります。
