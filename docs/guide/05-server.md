# サーバー（β）

携帯から、家の外でも本棚を検索して読めるようにする機能です。**β** なので、API と保存形式は予告して変えることがあります。

本棚を出す形は 2 つあります。

| | この PC をサーバーにする | 単独サーバー |
|---|---|---|
| 読める間 | この PC が動いている間 | サーバーの機械が動いている間 |
| 用意するもの | なし | 常時動いている Windows 機 |
| 本棚の更新 | そのまま | デスクトップ版から差分を送る |

どちらも入れるまでは何も動きません。

## この PC をサーバーにする

1. **設定 → サーバー（β）→ この PC をサーバーにする** で出す先を選び、**始める** を押します。
   - **同じネットワークの携帯へ:** 選んだアドレスで、自己署名の証明書を使って待ち受けます。
   - **トンネルやリバースプロキシの裏:** `127.0.0.1:38777` を平文で待ち受けます。Tailscale Funnel や Caddy などで、公開 URL からここへ転送してください。
2. **携帯を追加** を押し、Android 版で QR を読み取ります。QR は 10 分だけ有効で、一度だけ使えます。

## 単独サーバーを置く

### 1. 組み立てる

今のところ、単独サーバーはソースから組みます。

```powershell
cargo build --release --manifest-path src-tauri/Cargo.toml --example piep-server
```

できた `src-tauri/target/release/examples/piep-server.exe` をサーバーの機械に置きます。

### 2. 置き場を作る

```powershell
piep-server init --data D:\piep-server --url https://<デスクトップ版から届く URL>/
```

設定（`server.toml`）を作り、**管理者用の登録文字列**を画面に出します。30 分有効で、一度だけ使えます。
画面の外に残さないでください。出し直すときは `piep-server admin-pair --data D:\piep-server --url ...` を使います。

### 3. 出し方を決めて動かす

`server.toml`:

```toml
listen = "127.0.0.1:38777"
# admin_listen = "127.0.0.1:38778"
public_url = "https://example.ts.net/"
# tls = "self-signed"
```

| 出し方 | 設定 |
|---|---|
| リバースプロキシ（Tailscale Funnel、Caddy など） | `listen` は `127.0.0.1` のまま。公開 URL からここへ転送する |
| サーバー自身の TLS（自己署名） | `listen = "0.0.0.0:38777"`、`tls = "self-signed"` |
| サーバー自身の TLS（証明書ファイル） | `listen = "0.0.0.0:38777"`、`tls = { cert = "...", key = "..." }` |

`127.0.0.1` 以外で待ち受けるには `tls` が必須です。無ければ起動しません。

インターネットへ出すときは `admin_listen` で管理の口を分け、**`listen` の口だけ**を公開してください。読み手の口には
管理の API がありません。デスクトップ版は、家の LAN や VPN から管理の口につなぎます。

```powershell
piep-server serve --data D:\piep-server
```

落ちても立ち上がるようにするには、起動時に実行するスケジュールタスクへ登録してください。

### 4. デスクトップ版からつなぐ

**設定 → サーバー（β）→ 別の機械のサーバーにつなぐ** に登録文字列を貼ります。管理者の鍵は Windows の資格情報マネージャーに
保存されます。つないだら **今すぐ送る** を押してください。初回は本棚の全部を送るので時間がかかります。止めても、次の送信が
続きから使います。

**自動で送る** を入れると、本棚が変わってから 5 分静かになったときに送ります。

送るのは本棚の DB の写しと、本文・画像・作者とシリーズの画像・コレクションの表紙です。pixiv と FANBOX のログイン情報は送りません。

### 5. 携帯を登録する

**携帯を追加** を押して、Android 版で QR を読み取ります。登録の解除はすぐに効きます。

## 守り

- 無認証で答えるのは接続の確認と登録だけです。本棚はすべて鍵が要ります。
- 鍵はサーバーにハッシュだけが残ります。登録文字列は記録に残りません。
- 登録の試行は 1 分に 10 回までです。
- 応答に、サーバーの中のパスは出ません。
- 読み手の鍵では、本棚を書き換えられません。読み手が変えられるのは読書位置だけです。
- サーバーは、携帯が読むのに使わない表（更新確認の対象、AI の下書きなど）を受け取りません。
- 一覧から消えたファイルは、すぐには消さず `library-trash` に 7 日残します。直前の DB は `library\piep.db.previous` に残ります。

## 今のところできないこと

- サーバーでの更新確認・保存（デスクトップ版で行って送ります）
- 携帯からの本棚の変更
- 意味検索（全文検索は使えます）
- 動画・音声・PDF の資産の読み取り
- デスクトップ版の読書位置との同期（携帯どうしは同期します）

先の予定は [仕様](../plan/server-mode.md) にあります。
