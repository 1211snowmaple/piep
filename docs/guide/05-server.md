# サーバー（β）

携帯から、家の外でも本棚を検索して読めるようにする機能です。**β** なので、API と保存形式は予告して変えることがあります。

本棚を出す形は 2 つあります。

| | この PC をサーバーにする | 単独サーバー |
|---|---|---|
| 読める間 | この PC が動いている間 | サーバーの機械が動いている間 |
| 用意するもの | なし | 常時動いている Windows 機 |
| 本棚の更新 | そのまま | デスクトップ版から差分を送る |

どちらも入れるまでは何も動きません。

## この PC をサーバーにする

1. **設定 → サーバー → この PC をサーバーにする** で出す先を選び、**始める** を押します。
   - **同じネットワークの携帯へ:** 選んだアドレスで、自己署名の証明書を使って待ち受けます。
   - **トンネルやリバースプロキシの裏:** `127.0.0.1:38777` を平文で待ち受けます。Tailscale Funnel や Caddy などで、公開 URL からここへ転送してください。
2. **携帯を追加** を押し、Android 版で QR を読み取ります。QR は 10 分だけ有効で、一度だけ使えます。

## 単独サーバーを置く

常に動いている Windows の機械に置くと、デスクトップ版の PC を閉じていても携帯から読めます。

### 1. 入れる

[リリース](https://github.com/1211snowmaple/piep/releases/latest)から `piep-server-<版>-windows-x64.zip` を取ってきて展開し、
`piep-server.exe` を開きます。管理者権限を求められたら許可してください。質問は次の 2 つです。

- **置き場所:** 本棚が入るので、大きいドライブを選べます。既定は `C:\ProgramData\piep-server` です。
- **外からどう届かせるか:**
  - **トンネルやリバースプロキシの裏に置く:** 公開 URL で、どこからでも使えます。`127.0.0.1:38777` で待ち受けるので、
    Tailscale Funnel や Caddy などで公開 URL からここへ転送してください。何を使うかは自由です。先に公開 URL を用意しておくと、
    そのまま入力できます。
  - **この機械の接続口で直接待ち受ける:** 自己署名の証明書で `38777` 番を開きます。届く範囲は、この機械のネットワーク次第です。

終わると起動時に自動で動くように登録され、**管理者用の登録文字列**が画面に出ます。30 分有効で、一度だけ使えます。
画面の外に残さないでください。出し直すときは次のコマンドを管理者権限で動かします。

```powershell
& "C:\ProgramData\piep-server\piep-server.exe" admin-pair --data "C:\ProgramData\piep-server"
```

質問はコマンドの引数で飛ばせます。起動の仕組みを自分で用意するなら `--no-task` を付けます（管理者権限は要りません）。

```powershell
piep-server install --data D:\piep-server --expose proxy --url https://<公開 URL>/
```

### 2. 落ちたとき・更新

- 落ちても自分で立ち上がります。記録は `<置き場所>\state\watchdog.log` にあります。
- 新しい版は、夜（既定は 3 時から 6 時）に自動で当たります。止まるのは数十秒です。起動しない版は自動で前の版に戻します。
- デスクトップ版の「サーバーを今すぐ更新」で、すぐに当てられます。
- 時間帯を変えたり自動をやめたりするときは、`server.toml` の `[update]` を書き換えて再起動します。

```toml
[update]
auto = true              # false なら、デスクトップ版から頼んだときだけ当てます
window = "03:00-06:00"
```

- やめるときは `piep-server uninstall` です。起動時の登録を消して止めます。置き場所は消さないので、要らなければ自分で消してください。

### 3. 設定を変える

`server.toml` は `<置き場所>` にあります。書き換えたら再起動してください。

| 置き方 | 設定 |
| --- | --- |
| トンネルやリバースプロキシの裏 | `listen` は `127.0.0.1` のまま。`public_url` に公開 URL を書く |
| 直接待ち受ける | `listen = "0.0.0.0:38777"`、`tls = "self-signed"` |
| 自分の証明書 | `tls = { cert = "...", key = "..." }` |

`127.0.0.1` 以外で待ち受けるには `tls` が必須です。無ければ起動しません。

インターネットへ出すときは `admin_listen` で管理の口を分け、**`listen` の口だけ**を公開してください。
公開した口には管理の API がありません。デスクトップ版は、同じネットワークや VPN から管理の口につなぎます。

### 4. デスクトップ版からつなぐ

**設定 → サーバー → 別の機械のサーバーにつなぐ** に登録文字列を貼ります。管理者の鍵は Windows の資格情報マネージャーに
保存されます。つないだら **今すぐ送る** を押してください。初回は本棚の全部を送るので時間がかかります。止めても、次の送信が
続きから使います。

**自動で送る** を入れると、本棚が変わってから 5 分静かになったときに送ります。

送るのは本棚の DB の写しと、本文・画像・作者とシリーズの画像・コレクションの表紙です。pixiv と FANBOX のログイン情報は送りません。

### 5. 携帯を登録する

**携帯を追加** を押すと、アプリの入手先と登録の QR が出ます。アプリを入れてから、Android 版の「設定 → サーバーとの接続 → QR を読む」で読み取ります。登録の解除はすぐに効きます。

Android 版の更新は、アプリの「設定 → アプリの更新」から行います。OS の確認に答えると上書きされ、保存した作品と登録は残ります。

## 守り

- 無認証で答えるのは接続の確認と登録だけです。本棚はすべて鍵が要ります。
- 鍵はサーバーにハッシュだけが残ります。登録文字列は記録に残りません。
- 登録の試行は 1 分に 10 回までです。
- 応答に、サーバーの中のパスは出ません。
- 読み手の鍵では、本棚を書き換えられません。読み手が変えられるのは読書位置だけです。
- サーバーは、携帯が読むのに使わない表（更新確認の対象、AI の下書きなど）を受け取りません。
- 一覧から消えたファイルは、すぐには消さず `library-trash` に 7 日残します。直前の DB は `library\piep.db.previous` に残ります。

## 今のところできないこと

- サーバーでの更新確認・保存（デスクトップ版で行って送ります）
- 携帯からの本棚の変更
- 意味検索（全文検索は使えます）
- 動画・音声・PDF の資産の読み取り
- デスクトップ版の読書位置との同期（携帯どうしは同期します）

先の予定は [仕様](../plan/server-mode.md) にあります。
