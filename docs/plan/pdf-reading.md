# 添付の中の本文の続き

いまの決まりは [データの持ち方](../policy/04-data.md) の「添付の中の本文」にある。ここには、まだ作って
いないものと決めていないものだけを残す。

## この先

1. **一覧の文字数。** 一覧の数と文字数の絞り込みは投稿の本文だけを見ている。2万字の作品が「46字」として
   並び、「1万字以上」で絞ると外れる。直すには別の列を持ち、絞り込みと並べ替えの SQL を両方直す必要が
   ある。対象は6作品で、触るのは棚でいちばん熱い経路なので、いまは入れない
2. **OCR。** 文字の層の無い PDF が棚に現れてから

## 未決

- 段落の中に画像がある PDF をどう組むか。実物を待つ。いまは原本を見るほうで足りている
- 縦書きの PDF。構造ツリーの経路は書字方向に依らないが、行の組み直しは横書きしか扱えない。
  一字ずつが別の段落になったことを見張って、そのときは取り出しを断る
- 取り込んだ本文を編集したあと、取り出しの規則を直したらどうするか。編集は取り込み済みの本文を
  抱えたまま残る
