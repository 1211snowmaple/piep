# 検索・設定・差分の見直し

利用者が「探す」「条件を選ぶ」「変更箇所を見る」ときに、操作名と結果が一致することを優先する。

## 判断

- 全体検索に作品検索と画面移動を混ぜると、作品を探す入力欄にメニュー一覧が出る。ライブラリと画面・操作を明示的に分ける。ライブラリ側では実際の候補と、全結果を開く操作を出す。
- ライブラリ検索の入力確定で、勝手に先頭の作者・シリーズへ移動させない。Enterは入力語の検索を保ち、候補はクリックまたは矢印で選んだときに開く。IME変換を妨げない。
- 標準・入力した語・意味検索を検索欄で選べるようにし、URLと保存した検索にも残す。意味検索に対応しない過去版では明示的に標準へ戻す。
- 絞り込みは保存状態を入口にする。要確認の内訳、改稿の保存状況、読みかけ、編集、表紙を見つけやすくする。作者・タグだけでなく、シリーズ、日付、文字数、添付、容量、取得元、お気に入りの除外も既存の検索機能へ接続する。
- 条件の検索と作品の検索を分け、条件は適用前に確認・解除できるようにする。初期状態に「含める0・除外0」の空欄を並べない。
- 設定は「保存する」「使いやすくする」「管理する」でまとめる。項目名でも探せるようにし、既存のURLは維持する。よく使う表示設定を先に出し、一覧ごとの細かな指定や索引の作り直しは詳細へ収める。
- 差分は一致する文に色を付けない。比較する箱は中立色、追加と削除の文字列だけを着色する。
- 名前を固定の割合で切らない。作者・シリーズの識別に必要な名前は、実際の幅で折り返す。本文の抜粋やカードの題名はプレビューとして上限を持たせ、全文への導線を残す。進捗・操作履歴・更新の名前も同じ観点で確認する。
- 戻る・進む・更新は左上にまとめ、提示された丸い操作バーの見た目に揃える。

## 検証する操作

作品の本文語・作者・タグ・作品URLから探す、入力中の変換を確定する、検索方法を切り替える、保存した検索を開く、要確認の内訳を選ぶ、条件を解除する、設定項目を探す、長い名前を異なる幅で表示する、説明の一部分だけを削除した改稿を比較する。

幅とテーマの画面回帰だけでなく、検索条件が実際の取得パラメーターとデータベースの結果に反映されることを確認する。

## 実施した検証（2026年10月30日）

- フロントエンド726件、Rust756件が通過。既存の手動検証向け9件は無視対象のまま。
- 幅900・1200・1440、ライト・ダーク、表示倍率100・150・200%のブラウザ検証で143件が通過。共通動作を各組み合わせで重複させない541件は設定により省略。
- 型検査、ESLint、Clippy、rustfmt、配布用フロントエンドのビルド、ドキュメントの画面・コマンド整合性を確認。
- 絞り込みの適用前後、全体検索と日本語変換、設定の履歴移動、長い名前の折り返し、差分の一致部分、提供元が異なる同じ作品番号、URLの検索、お気に入り除外を確認。
- 画面・検索の検証には架空のデータと一時データベースを使用。利用者のライブラリの削除や再構成は行っていない。
