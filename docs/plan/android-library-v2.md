# 新ライブラリと Android の設計境界

策定日: 2026-11-09。状態: 設計を改訂。新しい端末保存・同期・配信への接続は未完了。

Android 側の詳細は [Android の新ライブラリ基盤設計](https://github.com/1211snowmaple/piep-android/blob/codex/android-library-v2-design/LIBRARY-V2.md) を正本とする。
現行の Android は Tauri・React・Rust のアプリで、既存 API を使ったオンライン読書と
選択保存を実装している。この文書は、そのアプリを新ライブラリへ接続する境界を定める。

## 決定

- Android でサーバーの SQLite や Windows のパスを直接開かない。全棚を複製せず、
  作品と snapshot/edit を固定した読書用 bundle だけを選択保存する。
- Tauri と既存 UI を継続し、端末側に全文検索エンジン・AI・取得元へのログインを持ち込まない。
- raw/Zstandard の形式・長さとハッシュ・分割構成の検査は、小さな Tauri 非依存の Rust crate
  に切り出して共有する。デスクトップの `library` 全体をコピーしない。
- body・metadata・固定した資産と対応表・原稿境界・表示物・アンカーを、同じ保存状態から配信する。
  Android に別の小説・記事解釈器を実装しない。生成 HTML は原本の代わりにしない。
- 端末の接続登録、server、library、利用者、同期 epoch、接続変更の世代を別の値にする。
  URL・旧整数 ID・取得元 ID だけで保存物や未送信操作の所属を決めない。
- 新 HTTP API は `/api/v2` とし、登録文字列の版・実体形式・reader の版とは区別する。
  内部 Rust 型の serde 出力をそのまま恒久的な通信契約にせず、UUID・ハッシュ・64 bit 値を
  境界で検査・変換する。64 bit の更新世代を JavaScript の `number` に丸めない。
- 実体は、利用者→棚→作品→snapshot/edit→file→chunk の所属を認証してから渡す。
  ハッシュを知っているだけでは取得できず、ETag / 304 も認証後に扱う。
- オフラインの保存指定・位置・outbox・転送台帳は SQLite を正本にする。本文と画像が
  ファイルで残っていても、利用者の状態までファイルから復元できるとは仮定しない。
- 検証済み実体を公開した後、必要な全 file がそろった bundle と現在参照を一度に確定する。
  未完成の転送は旧保存版を置き換えず、再開では検証済みの chunk を再利用する。
- 現形式では小さい単一実体が最大 8 MiB、大きな file の分割は 4 MiB である。
  端末の chunk 受信・復元上限を 4 MiB と誤認しない。
- 位置とお気に入りは期待する更新世代・要求 UUID・receipt で同期する。
  端末時刻で勝者を決めず、古い応答が新しい未送信操作を消さないようにする。
  操作の基準には syncEpoch も含め、サーバー復元前の未完了要求を新規操作として適用しない。
- 画面と独立して続く処理は永続的な処理台帳を正本にする。短い同期や自動先読みは WorkManager、
  API 34 以降で利用者が開始する大容量の転送は UIDT、非対応 OS は foreground worker に分ける。
  Kotlin は実行制御を担当し、Rust の共通サービスを WebView 無しで起動できる境界を作る。
- 旧端末の保存物と位置は先に保持し、サーバーの移行対応表と元ハッシュで確認できたものだけを
  新しい UUID へ結ぶ。対応不明・取得不能な作品を初期化や再取得で置き換えない。

## 変更に伴う実装単位

1. 共有する実体形式と wire DTO の抽出、試験ベクトル、Android 向けコンパイル。
2. 認証・対応版・所属検査を持つ API v2 と、保存状態に固定した読書 bundle の配信。
3. Android の新端末 DB、選択保存・cache の区別、移行器、失敗時の復旧。
4. 世代付き同期と Android の background worker、スマホ・タブレットでの照合。

これらを接続する前に、旧 API を新ライブラリ対応と見なして有効化しない。
デスクトップの移行が未完了でも旧端末の保存物は保持し、新しい棚への切り替えと
旧保存物の解放を分ける。デスクトップ・Android とも本番データの自動変換はまだ行わない。
